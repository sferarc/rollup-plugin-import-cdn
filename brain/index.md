# Brain

Knowledge vault for rollup-plugin-import-cdn, readable as an Obsidian vault. One topic per file, wikilinks for cross-references. It records how the plugin works and why it is shaped the way it is, with a source path, commit or pull request behind every claim. Where something is not known, the note says so.

The README is the user documentation and stays the authority on the public API. These notes are for someone changing the code.
